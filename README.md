# layer1984

Private research and design repo for a Kaspa-based "extra layer of the internet" — a Tor-like (but faster and more private) overlay that platforms such as 1984 can run on.

Access is intended to be hardware-gated. Prefer open mining hardware (see OpenMiner work by @elldeeone) + Kaspa node capabilities.

**Status:** Early concept / research. Testnet-10 first.

**Key credible sources:**
- OpenMiner announcement by Luke Dunshea (@elldeeone): https://x.com/elldeeone/status/2105643604446494781

# layer1984

Private research notes for a hardware-gated Kaspa overlay that a site such as 1984 might use.

**Status:** Evaluated 13 Oct 2026. See [EVALUATION.md](EVALUATION.md). A Tor-like packet layer does not fit on Kaspa. The useful pieces are a local node, a device key, and other people's privacy research. Testnet-10 only if a later experiment is run. This repo stays private until there is an explicit decision to open it.
